🚀 Что такое скиллы?

Скилл — это процедурная память Гермеса. Готовая инструкция, которую я загружаю, чтобы сделать задачу правильно и без лишних вопросов.

Вместо того, чтобы гадать как делать — я читаю скилл и сразу знаю:

  • какие команды запускать
  • в каком порядке
  • какие подводные камни есть
  • что делать если что-то пошло не так

🔌 Как подключать скиллы

🎯 /skill название — прямо в чате

Самая частая команда. Пишешь в диалоге и я сразу загружаю скилл:

/skill grove-street-crew
/skill web-animations
/skill ui-ux-pro-max
💡
Совет: Можно несколько скиллов за раз — /skill grove-street-crew, потом /skill web-animations. Каждый новый добавляется.
🎯 Загрузка при старте (флаг -s)

Если запускаешь Гермес из терминала — можно сразу загрузить скиллы:

hermes -s grove-street-crew # загрузить один
hermes -s ui-ux-pro-max -s web-animations # или несколько
🎯 CLI команды для скиллов
hermes skills list # список установленных
hermes skills browse # все доступные в каталоге
hermes skills search лендинг # поиск по названию/описанию
hermes skills install имя # установить из каталога
hermes skills update # обновить устаревшие
hermes skills config # включить/выключить на платформах
🎯 Внутри диалога (slash-команды)
/skill название # загрузить скилл
/skills # поиск/установка скиллов
/reload-skills # пересканировать папку skills/

⚡ Как Hermes создаёт скиллы

Когда я решаю сложную задачу, нахожу подводные камни или ты говоришь «запомни это» — я могу сохранить процедуру как скилл.

Вот как это работает:

# Я вызываю skill_manage внутри себя (ты этого не видишь)
skill_manage(action="create", name="my-skill", content="...")

# Или обновляю существующий:
skill_manage(action="patch", name="my-skill", old_string="...", new_string="...")

# Или удаляю устаревший:
skill_manage(action="delete", name="my-skill")
🧠
Памятка: Есть ещё self-learning скилл — он автоматически харвестит золотые пути из сессий и предлагает сохранить их как новые скиллы. Сам себя улучшает.

💎 Полезные советы

🔥
Банда — база. На любую крупную задачу загружай grove-street-crew. CJ сам распределит между профи: кто пилит код, кто тестит, кто дизайн делает.
🎯
Скиллы накапливаются. С каждым сложным проектом я запоминаю процедуры. Чем больше скиллов — тем быстрее и качественнее я работаю.
🧠
Self-learning. Этот скилл сам харвестит удачные решения и превращает их в новые скиллы. Включается автоматически на сложных задачах.
📁
Где лежат скиллы: ~/.hermes/skills/ — каждый скилл в своей папке. Можно заглянуть, почитать, отредактировать.
🔄
Не видишь скилл после загрузки? Сделай /reset (новый диалог) — скиллы загружаются при старте сессии.
