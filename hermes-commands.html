⚙️ Глобальные опции (флаги к любой команде) — 20 штук

-h, --help --version, -V -z, --oneshot PROMPT --usage-file PATH -m, --model MODEL --provider PROVIDER -t, --toolsets TOOLSETS --resume, -r SESSION --continue, -c [SESSION_NAME] --worktree, -w --accept-hooks --skills, -s SKILLS --yolo --pass-session-id --ignore-user-config --ignore-rules --safe-mode --tui --cli --dev

-z PROMPT — Режим одного запроса: отправить промпт и вывести ТОЛЬКО финальный ответ в stdout. Без баннера, спиннера, превью инструментов и session_id.
--usage-file PATH — Только для one-shot: записать JSON-отчёт (стоимость, токены, модель, api_calls) в PATH. Пишется даже при ошибке.
-m MODEL — Переопределить модель для вызова (напр. anthropic/claude-sonnet-4.6). Также через переменную HERMES_INFERENCE_MODEL.
--provider PROVIDER — Переопределить провайдера для вызова (напр. openrouter, anthropic).
-t TOOLSETS — Список наборов инструментов через запятую для этого вызова.
--resume, -r SESSION — Возобновить сессию по ID или названию.
--continue, -c [SESSION_NAME] — Возобновить сессию по имени, или последнюю, если имя не указано.
--worktree, -w — Запуск в изолированном git worktree (для параллельных агентов).
--accept-hooks — Авто-одобрение неизвестных shell хуков без TTY. Для CI / headless.
--skills, -s SKILLS — Предзагрузить один или несколько скиллов для сессии.
--yolo — Обойти все подтверждения опасных команд.
--pass-session-id — Включить ID сессии в системный промпт агента.
--ignore-user-config — Игнорировать ~/.hermes/config.yaml, использовать встроенные дефолты.
--ignore-rules — Пропустить авто-инъекцию AGENTS.md, SOUL.md, .cursorrules, памяти и скиллов.
--safe-mode — Режим диагностики: отключить ВСЕ кастомизации (включает --ignore-user-config и --ignore-rules).
--tui — Запустить современный TUI вместо классического REPL.
--cli — Принудительно классический REPL (prompt_toolkit).
--dev — С --tui: запускать TypeScript через tsx (без сборки dist).
